⚠️ **重要观察**：Logo 是白底 + 浅蓝主色的圆形徽章。网站可在开屏和 Hero 使用深色场景，但必须保留冷白与品牌蓝，并为 Logo 和正文提供足够对比度。

### 2.2 从 Logo 采样的真实主色板

**通过像素统计得出**（不是浮浮酱凭空发挥）：

| HEX | RGB | 占 Logo 面积 | 语义 | 用途 |
|-----|-----|-------------|------|------|
| `#F0F0F0` | rgb(240,240,240) | 57.4% | 象牙白 | **主背景**（不是黑色！）|
| `#0078D8` | rgb(0,120,216) | 5.8% | **科技蓝**（品牌主色）| 主 CTA、标题重音、Logo 主体 |
| `#0078F0` | rgb(0,120,240) | 1.9% | 亮科技蓝 | 交互态高亮 |
| `#1878C0` | rgb(24,120,192) | 1.9% | 深科技蓝 | 副标题、边框 |
| `#D8F0F0` | rgb(216,240,240) | 4.8% | 冰晶浅蓝 | 卡片底色 |
| `#6090A8` | rgb(96,144,168) | 1.6% | 灰蓝 | 正文文字 |

**网站场景扩展色**（用于页面节奏，不替代 Logo 主色）：

| HEX | 语义 | 使用范围 |
|---|---|---|
| `#0F1428` | 深蓝黑 | 开屏、Hero、电路空间 |
| `#181E32` | 抬升深蓝 | 深色表面与过渡区 |
| `#F1F2F4` | 冷灰白 | 内容区背景、黑白照片留白 |
| `#131416` | 近黑 | 数据区和黑白粒子背景 |
| `#E8B36A` | 暖琥珀 | 仅用于统计数字的辉光管高光 |

**从上面可以推断出的品牌 DNA**：

- 科技蓝是唯一长期品牌色，暖琥珀只作为局部数据强调。
- 深蓝、冷灰和近黑按章节交替，避免全页颜色疲劳。
- 视觉强调工程、学术和竞赛，不使用无意义的霓虹装饰。

### 2.3 反 AI Slop 清单（严禁使用）

按 huashu-design §6.2 严禁在本项目使用：

| ❌ 禁用元素 | 原因 |
|-----------|------|
| 紫色渐变（`#A855F7` 系）| 训练语料味 · 与 Logo 无关 |
| 青紫霓虹 glow | GitHub-dark 撞衫 · 与 Logo 无关 |
| Emoji 作图标（💡⚡🔬🔆✨🏆 等）| 专业性不足的凑数 |
| 全页连续使用同一深蓝底 | 缺乏章节节奏，容易产生审美疲劳 |
| 圆角卡片 + 左 border accent | 2020-2024 烂大街 |
| Inter/Roboto 作 display 字体 | 无个性、无学术感 |
| SVG 手画协会 logo/成员像 | 比例诡异 · 失去品牌识别 |
| GPU 粒子系统（>3000）| 手机卡死 · 与协会气质不符 |

## 3. 字体系统

**Logo 上是艺术字体，正文不模仿**。选真实可用字体：

| 层级 | 字体家族 | 权重 | 场景 |
|------|---------|------|------|
| Display（超大标题）| **Cormorant Garamond** + **Noto Serif SC** | 600 | Hero 主标题、金句 |
| H1-H3 | 同上 | 500 | 章节标题 |
| 正文 | **Inter** + **Noto Sans SC** | 400 | 段落文字 |
| 数据/代码 | **JetBrains Mono** | 500 | 数字、时间戳、代码 |
| 强调 | **Lora** | 500 | 引言、slogan |

- 中文 - 英文之间自动加入四分之一 em space（`text-wrap: pretty`）
- **禁止**用 Inter 或 Roboto 做 display 字号（会掉品位）

---

## 4. 网格与留白

- 桌面：容器 `max-w-6xl`（1152px），左右 padding `1.5rem`
- 移动：全宽，左右 padding `1rem`
- 段间距：8 倍数系统（`0.5 / 1 / 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24`）
- **留白比例**：正文区任一段落**必须至少 40% 是空白**（防信息焦虑）

## 5. 动画系统（性能优先）

**性能红线**：

| 场景 | 上限 |
|------|------|
| 首屏加载 JS | < 100 KB gzip |
| 首屏 LCP | < 2.5s（4G 网络）|
| 帧率 | ≥ 60fps（桌面）、≥ 30fps（移动）|
| GPU 粒子数 | 桌面 ≤ **1500**、移动 ≤ **500** |
| 同时运行的 rAF 循环 | ≤ 2 个 |

**允许的动效**：

| 动效 | 触发 | Duration | Easing |
|------|------|---------|--------|
| Fade-up 入场 | IntersectionObserver | 600ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 悬浮微反馈 | :hover | 200ms | `ease-out` |
| 数字滚动 | 首屏可见 | 1200ms | `ease-out` |
| 页面切换 | 路由 | 400ms | `ease-in-out` |
| 光斑呼吸（CSS） | 常驻 | 6s loop | `ease-in-out` |
| 标题通电点亮 | 点击 Enter Site 后 | 1900ms | 单一 GSAP 时间轴 |
| 开屏到主页交接 | 点击 Enter Site 后 | 1500ms | `cubic-bezier(0.16, 1, 0.3, 1)` |

**禁止的动效**（曾把主人浏览器卡死过）：

- ❌ 10000+ 粒子系统
- ❌ WebGL Shader（除非有强论证）
- ❌ 逐字符打字机效果（除非用户明确要求）
- ❌ 大幅视差滚动 + 持续 3D 摄像机运动

## 6. 灵感锚点（写代码前 trace 到具体作品）

**不要说"Awwwards 风"这种模糊表达**。要说：

| 参照作品 | 学的是什么 |
|---------|-----------|
| **Stripe.com Home（2024-2026）** | 明度对比 + 微妙渐变 |
| **Linear.app** | 排版层级 + Serif Display + 干净留白 |
| **MIT Media Lab** | 学术气质 + 网格 + 项目卡索引 |
| **Anthropic.com（首页）** | 大字标题 + Cormorant + 无 emoji |

**参考边界**：

- makemepulse：只借鉴开屏节奏、用户主动进入和连续视觉交接。
- Rainform：只借鉴状态驱动场景、固定 seed 和渲染降级。
- Ark-Particle-Imitate：只借鉴图片采样和短时粒子聚合。
- 明日方舟视觉：借鉴信息层级、编号、网格、纹理和动线；不复制角色、Logo 和活动主视觉。
